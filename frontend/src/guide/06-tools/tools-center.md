工具中心集中管理智能体可调用的能力插件，以及平台运维使用的实用工具。能力插件面向智能体，可用于查询数据、调用外部接口、检索知识库或连接 MCP 服务；运维工具面向管理员，可用于连通性检测、导出和维护类操作。

每个工具都有详情页，可查看是什么、给谁用、怎么用，以及参数说明。可用工具支持在线试运行，原始返回数据会收纳在开发者折叠区，不会默认铺开。

创建工具时可选择手动新建，也可使用对话式构建生成草稿。MCP 工具可按名称、传输方式、服务地址和认证方式配置；当前外部 MCP 执行能力标记为即将支持，仍可保存和展示。
