3. 基础操作流程

3.1 登录系统

  1. 打开访问地址：http://112.64.45.22:8088/#/
  2. 点击右上角“登录”。
  3. 输入手机号和密码。
  4. 点击“确认登录”。
  5. 看到右上角显示“已登录”，表示登录成功。

3.2 使用 AI 咨询

  1. 进入“妇儿工作智能AI助手”页签。
  2. 在底部输入框输入问题。
  3. 点击发送按钮。
  4. 等待 AI 回复。
  5. 根据回答判断是否需要转接人工服务。

建议提问方式：

  • 把问题说清楚，例如“居民想咨询遭遇家庭暴力后如何求助”。
  • 一次只问一个主题，便于回答更清晰。
  • 不输入不必要的身份证、住址、银行卡等敏感信息。

3.3 查看服务电话

  1. 手机端点击顶部“服务信息”；桌面端可查看右侧服务区域或家庭云服务入口。
  2. 找到对应服务点。
  3. 点击“复制”按钮复制电话，或直接拨打。
  4. 告知居民服务时间和地址。

3.4 查看历史记录

  1. 确认已登录。
  2. 点击右上角“☰”。
  3. 点击“我的问答记录”。
  4. 在弹窗中查看历史咨询记录。

3.5 开启隐私保护

  1. 确认已登录。
  2. 点击右上角“隐私保护”。
  3. 页面显示“隐私保护中”后，本次问答不会写入历史。
  4. 如需继续保存记录，再次点击关闭隐私保护。
