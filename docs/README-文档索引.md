# 文档索引（v2）

v2 依据实测核对做了措辞收敛与文档补齐，共四类目录。历史修订说明如需对外同步，请由交付负责人从版本记录和验收报告中整理。

## 目录结构
- **操作手册/**（面向使用者，可进产品操作文档，13 篇）
- **商业化文档/**（对外售卖套件 + 版本能力边界表，11 篇）
- **开发者文档/**（面向集成方，2 篇）
- **交付内部文档/**（含敏感信息，**不对外分发**，4 篇）

## 关键文档
- 《商业化文档/10-版本能力边界表》——对内外统一口径总闸，宣传/POC/采购问卷一律以此为准。
- 《开发者文档/OpenAI兼容API接入说明》——集成方零改造接入。
- 《交付内部文档/*》——默认账号、端口、工具安全、备份恢复，仅内部与实施用。

## 分发原则
| 目录 | 可否对外 |
|---|---|
| 操作手册 | 可（面向使用者） |
| 商业化文档（"可用"项） | 可（售前）；模板项需商务填写 |
| 开发者文档 | 可（面向对接客户技术） |
| 交付内部文档 | 否（含默认账号/内网端口，仅内部） |

## 口径纪律（源自本次核对）
1. 只承诺"已实现"；"需配置""方案承诺""二期"如实标注，不夸大。
2. 引用为"来源片段级"，不宣称页码级定位。
3. SLA/高可用/上线周期结合客户架构确认。
4. 对外文档不出现默认账号密码明文。
