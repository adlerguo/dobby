# SLA 与服务支持说明（模板）

> 对外服务承诺框架。具体时效以正式合同约定为准，方括号内容按公司服务能力填写。

## 1. 服务范围

- 平台软件的部署实施支持
- 使用培训与文档
- 故障响应与问题处理
- 版本升级支持

## 2. 支持渠道

| 渠道 | 用途 | 响应 |
|---|---|---|
| [工单系统/邮箱] | 一般问题、需求 | [工作日 N 小时内] |
| [专属群/电话] | 紧急故障 | [M 小时内] |

## 3. 故障分级与响应时效（示例）

| 级别 | 定义 | 响应时效 | 处理目标 |
|---|---|---|---|
| P1 严重 | 核心功能不可用、业务中断 | [30 分钟] | [尽快恢复] |
| P2 高 | 主要功能受影响，有临时规避 | [2 小时] | [1 工作日] |
| P3 中 | 部分功能异常，不影响主流程 | [1 工作日] | [按版本计划] |
| P4 低 | 咨询、优化建议 | [2 工作日] | [评估排期] |

## 4. 可用性说明

- 私有化部署的整体可用性取决于客户环境（主机、网络、数据库）。平台侧提供高可用部署方案与健康监控能力。
- 具体可用性承诺（如 [99.x%]）需结合部署架构在合同中约定。

## 5. 升级与维护

- 提供版本更新说明（见《版本更新说明》）。
- 升级遵循"先备份、灰度、可回滚"原则。
- 维护窗口与升级安排提前与客户沟通。

## 6. 责任边界

平台负责软件功能与缺陷修复；主机、网络、数据备份、访问管理等环境运维由客户负责，双方在合同中明确分工。
