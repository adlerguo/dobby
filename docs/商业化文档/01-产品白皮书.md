# 产品白皮书

> 面向企业决策者与采购团队的产品价值说明。

## 1. 我们解决什么问题

企业想用大模型提升效率，但普遍卡在四件事上：模型接入分散难管理、企业知识无法安全利用、智能体从搭建到上线链路长、上线后无法观测与治理。本平台把这四件事收进一套轻量工作台，让企业以最小成本跑通"从模型到业务应用"的闭环。

## 2. 核心价值主张

- **一套工作台，闭环交付**：模型接入、知识库、智能体、发布、观测审计在同一平台完成，减少跨系统集成。
- **数据不出域**：支持完全私有化部署，企业知识与对话数据留在自有环境。
- **回答可追溯**：基于企业知识库作答并给出来源片段引用（来源文档与命中片段），业务敢用。
- **可治理、可控成本**：多渠道模型容错、密钥限额、全链路审计与观测。
- **轻量易落地**：从零到一个可用智能体，最快 1 天跑通。

## 3. 能力全景

| 能力域 | 说明 |
|---|---|
| 模型接入与网关 | 统一接入多供应商模型，多渠道加权路由、失败切换与熔断，密钥加密 |
| 企业知识库（RAG） | 文档上传、解析、切分、向量化，混合检索 + 引用回链，命中测试 |
| 智能体工厂 | 模板/空白创建，提示词、知识库、工具、检索参数可配 |
| 工具与 MCP | 能力插件与运维工具，支持 MCP 编排 |
| 发布与开放 | 一键发布外部应用，标准接口调用（含 OpenAI 兼容），密钥限额 |
| 观测与审计 | 成功率、延迟、用量、运行轨迹、操作审计与导出 |
| 权限与多租户 | 四级 RBAC、租户隔离、工作空间 |

## 4. 差异化定位

市场上相关产品各有侧重，本平台的定位是"轻量、闭环、易私有化"：

- **对比"模型网关型"产品**（如 SiliconFlow 一类）：它们强在统一接入与调度；本平台在具备多渠道路由与容错的同时，把知识库、智能体、发布、观测补齐成完整业务闭环，而不仅是模型入口。
- **对比"大型 AI 基础设施/数据智能平台"**（如星环一类）：它们能力全面但偏重、实施成本高；本平台以轻量交付为目标，适合希望快速上线、不想背负重型平台的企业。
- **对比"自研大模型 + AIGC 产品"**（如出门问问一类）：它们强在自有模型与内容生成；本平台不绑定单一模型，让企业自由选择并统一治理多家模型，聚焦"把企业知识用起来"。

一句话：**当企业需要的是"快速、安全地把自己的知识变成可用、可治理的 AI 助手"，而不是一套重型平台或单一模型时，本平台是更合适的选择。**
