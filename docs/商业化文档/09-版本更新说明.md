## v1.0 — 2026-07-22 首个正式版本

**核心能力**
- 模型接入与网关：多供应商模型统一接入，多渠道加权路由、失败自动切换与熔断，密钥加密存储。
- 企业知识库：文档上传、解析、切分、向量化，混合检索与引用回链，命中测试。
- 智能体工厂：模板/空白创建，提示词、知识库、工具、检索参数可配。
- 工具中心：能力插件与运维工具，支持 MCP 配置。
- 发布与开放：一键发布外部应用，支持标准接口调用（含 OpenAI 兼容）与流式返回，密钥可设速率与配额。
- 观测与审计：成功率、延迟、用量、运行轨迹；操作审计支持检索与导出。
- 权限与多租户：四级角色权限、租户隔离、工作空间。

**部署**
- 支持私有化部署，数据不出域。
