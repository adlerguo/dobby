# 版本能力边界表

> **对内对外统一口径的总闸。** 销售、售前、交付、文档一律以此表为准，避免把"需配置""方案承诺""二期"的能力说成"已实现"。POC 和采购问卷都会验，口径一致才不会翻车。

## 图例
- ✅ **已实现**：代码中已具备，开箱或简单配置即用。
- ⚙️ **需配置**：能力存在，但需管理员显式配置/授权后才生效。
- 📐 **方案承诺**：不是代码自动保证，取决于客户部署架构与商务约定。
- 🕒 **二期/即将支持**：规划中或标注"即将支持"，当前不可用于生产。

## 使用规则
1. 对外宣传只承诺 ✅ 项；⚙️ 项说明"需配置"；📐 项说"结合客户架构确认"；🕒 项说"规划中/即将支持"，**不得说成已具备**。
2. POC 验收题只围绕 ✅ 与已配置好的 ⚙️ 能力设计。
3. 本表随版本更新，发版时同步维护。
