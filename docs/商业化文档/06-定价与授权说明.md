# 定价与授权说明（模板）

> 本文为对外报价框架模板，具体价格与条款以正式商务合同为准。请商务团队按公司策略填写方括号内容。

## 1. 授权方式

平台以**私有化部署授权**为主，按企业为单位授权，部署在客户自有环境。

## 2. 版本与能力划分（示例框架）

| 版本 | 适用 | 能力范围 |
|---|---|---|
| 基础版 | 单部门/单场景试点 | 模型接入、知识库、智能体、发布、基础观测 |
| 标准版 | 多部门/多场景 | 基础版 + 工作空间、完整权限、审计导出、多渠道治理 |
| 企业版 | 集团/高合规要求 | 标准版 + 高可用部署、专属支持、定制集成 |

> 各版本具体功能边界由产品与商务共同确定，上表为结构示例。

## 3. 计费口径（供参考的可选维度）

- **授权费**：按版本一次性/年度授权。
- **规模维度**：可按用户数、知识库规模、租户数等约定。
- **实施与服务费**：私有化部署实施、培训、定制开发。
- **模型调用成本**：外部模型 API 费用由客户直接向模型供应商结算，平台不加价；平台提供用量与成本观测帮助控费。
