# 私有化部署与交付说明

> 面向客户 IT/运维团队与交付实施人员，说明部署前提、流程与验收标准。

## 1. 部署形态

平台支持私有化部署，全部组件运行在企业自有环境（物理机、虚拟机或私有云），数据不出域。

## 2. 环境前置清单

部署前请确认以下条件（实际规格以交付时的版本说明为准）：

| 项 | 最小验证环境 | 生产建议 |
|---|---|---|
| 部署方式 | 容器化（Docker / 容器编排） | 容器编排集群 |
| CPU | 4 核 | 8 核以上 |
| 内存 | 8 GB | 16 GB 以上 |
| 存储 | 50 GB | 按知识库规模扩容（向量数据占用较大） |
| 数据库 | PostgreSQL（含向量扩展） | 独立部署、定期备份 |
| 缓存 | Redis | 独立部署 |
| 网络 | 能访问所选模型服务，或对接私有化模型 | 统一出口网关 |

> 说明：3072 维向量适合小规模验证；大规模知识库建议采用 1024/1536 维模型以获得更好检索性能。

## 3. 部署流程

1. **准备环境**：按前置清单准备主机、数据库、缓存。
2. **获取部署包**：由交付方提供部署包与版本说明。
3. **配置密钥**：生成并配置加密主密钥、令牌密钥（强随机值）。平台在弱密钥时会拒绝启动。
4. **一键启动**：执行部署脚本拉起服务。默认端口与暴露建议见内部《部署环境变量与端口说明》；生产原则是对外只暴露前端与反向代理后的 backend，其余组件限内网。
5. **初始化**：首次交付由实施人员提供管理员账号；首次登录后必须修改密码，并创建正式账号与角色（默认账号处理见内部《默认账号与初始化说明》）。
6. **接入模型**：在模型中心接入企业选定的对话与向量模型并测试连通。
7. **关闭演示模式**：确认生产模式，演示模型不参与真实路由。

## 4. 上线前检查（交付方执行）

- [ ] 默认管理员密码已修改
- [ ] 加密主密钥、令牌密钥为强随机值并已备份托管
- [ ] 已启用 HTTPS，反向代理配置正确（含流式接口不被缓冲）
- [ ] 对话模型、向量模型均接入并测试通过
- [ ] 至少一个知识库完成上传与命中测试
- [ ] 至少一个智能体完成对话验证
- [ ] 数据库与向量数据的备份策略已配置
- [ ] 演示模式已关闭

## 5. 交付验收标准

交付以"业务闭环可运行"为准，验收项：

1. 管理员可登录并完成账号、角色配置。
2. 可接入真实模型并通过连通测试。
3. 可创建知识库、上传文档、命中测试召回正确片段。
4. 可创建智能体并在调试对话中得到带引用的正确回答。
5. 可发布外部应用、生成密钥、通过接口成功调用（含流式）。
6. 观测中心可见运行数据，审计记录可查、可导出。

## 6. 运维与升级

- **备份**：定期备份数据库与向量数据；密钥托管在安全位置。
- **监控**：通过观测中心跟踪成功率、延迟、用量；异常渠道会自动熔断与恢复。
- **升级**：由交付方提供版本包与升级说明，升级前备份，遵循灰度/回滚流程。

## 7. 责任边界

平台负责软件层面的功能与可配置安全能力；主机安全、网络隔离、数据备份、访问审批等运维管理由企业方负责。双方在交付时明确分工。
