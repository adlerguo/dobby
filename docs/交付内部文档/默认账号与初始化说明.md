# 默认账号与初始化说明（内部交付版）

> **仅限内部与实施人员。禁止写入对外销售/客户文档。**

## 1. 初始化会生成的内容
首次启动会 seed：
- 默认租户：`default`
- 默认管理员：用户名 `admin`，初始密码 `Admin123!`
- 内置角色：平台管理员 / 租户管理员 / 构建者 / 普通成员
- 运行密钥（加密主密钥等）：首次生成并持久化，复用以避免已加密渠道失效

## 2. 交付时必做（强制）
1. **首次登录后立即修改 admin 密码**为强密码。
2. 为客户创建正式管理员账号，停用或改名默认 admin（按客户要求）。
3. 关闭演示模式（SEED_DEMO_MODE=false）。
4. 确认加密主密钥、JWT 密钥为强随机值并已安全托管。

## 3. 对客户文档的口径
面向客户的操作手册中，登录部分应写：
> "首次交付由实施人员提供管理员账号，首次登录后必须修改密码。"

**不要在对外文档中出现默认账号密码明文。**
