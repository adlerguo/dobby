# 部署环境变量与端口说明（内部交付版）

> 面向实施与运维。含默认端口与关键环境变量。**本文件为内部交付版，不随对外销售材料分发。**

## 1. 默认端口表（docker-compose 默认）

| 组件 | 容器端口 | 默认映射 | 生产暴露建议 |
|---|---|---|---|
| 前端 | 80 | 18080 | 经反向代理对外（HTTPS） |
| Backend API | 8001 | 8001 | 仅经反向代理暴露必要路径 |
| MaaS 网关 | 8100 | 8100 | 内网，不对外 |
| Sandbox | 8200 | 8200 | 内网，不对外 |
| MinIO | 9000/9001 | 9000/9001 | 内网，控制台 9001 不对外 |
| PostgreSQL | 5432 | 5432 | 内网，不对外 |
| Redis | 6379 | 6379 | 内网，不对外 |

**生产原则：对外只暴露"前端 + 反向代理后的 backend 必要路径"，其余组件全部限制在内网。** MaaS、Sandbox、数据库、缓存、对象存储均不应有公网入口。

## 2. 关键环境变量

| 变量 | 作用 | 生产要求 |
|---|---|---|
| DATABASE_URL | Postgres 连接串 | 改默认账号密码，独立部署 |
| REDIS_URL | Redis 连接 | 内网 |
| MINIO_ENDPOINT / 凭证 | 对象存储 | 改默认凭证 |
| MAAS_BASE_URL | 网关地址 | 内网地址 |
| SANDBOX_BASE_URL | 沙箱地址 | 内网地址 |
| 加密主密钥（渠道密钥加密） | 加密模型 Key | 强随机值；弱密钥会拒绝启动 |
| 令牌密钥（JWT 签名） | 会话令牌 | 强随机值 |
| enable_auto_code_tools | 代码类工具开关 | 默认 false，按需开启 |
| code_tool_allowlist | 代码工具允许清单 | 默认空 |
| http_tool_allowed_hosts | HTTP 工具主机白名单 | 默认空 |
| SEED_DEMO_MODE | 演示模式 | 生产必须关闭 |

> 数据库/对象存储的默认账号密码（如 app/pass、minio 默认凭证）仅用于本地开发，**生产部署必须全部替换**。

## 3. 上线端口检查
- [ ] 仅前端与反代 backend 对外，其余组件限内网
- [ ] 9001（MinIO 控制台）、5432、6379、8100、8200 无公网入口
- [ ] 已启用 HTTPS，反代对 SSE 接口关闭缓冲（proxy_buffering off）
