# 常见问题与自助排查

## 使用类问题

**无法创建智能体** → 先检查是否已接入并启用对话模型。

**回答没有引用** → 通常是：未绑定知识库 / 文档未解析完成 / 命中测试没召回合适片段。逐项排查。

**命中结果偏少** → 降低阈值、增大期望返回数（top_k），或用企业资料中的正式术语重新提问。

**引用片段不准** → 补充更清晰的原文资料，或拆分过长文档后重新上传。

**发布后应用无法调用** → 检查发布状态、访问密钥是否正确、关联智能体是否仍为"已启用"。进一步排查看观测中心运行轨迹和审计记录。

## 错误提示对照（把报错翻译成你能做的动作）

| 提示 | 含义 | 你可以做什么 |
|---|---|---|
| no_active_model_channel | 没有可用的真实模型渠道，或渠道被停用 | 到模型中心配置 Key 并测试连通 |
| provider_http_401 | 供应商拒绝请求 | 检查 Key 是否正确、权限是否足够、账号是否欠费 |
| dimension_mismatch | 知识库向量维度与模型不一致 | 确认知识库用的是当初创建时选的向量模型 |
| 速率/配额被拒（429） | 触发密钥限额 | 稍后重试，或让管理员调整密钥限额 |

## 性能类

**3072 维检索慢** → 大维度向量适合小库验证；大库建议用 1024/1536 维模型。

**已有文档的知识库不能换向量模型** → 为避免旧向量失效，请新建知识库或重建索引。
