# 登录与四步上手

## 第 0 步：登录

打开平台地址，使用管理员分配的账号登录。首次由平台提供的默认管理员账号登录后，请立即在"平台管理 → 用户管理"中修改密码并创建正式账号。

登录需要三项信息：租户、用户名、密码。租户代表你所在的企业空间；不同租户之间的数据完全隔离。

## 第 1 步：接入模型（模型中心）

进入"模型中心 → 模型广场"，至少接入两类模型：

- 一个对话模型（用于智能体回答）
- 一个向量模型（用于知识库检索）

选择模型后点击"接入使用"，填写访问密钥与服务地址，先点"测试并接入"。测试通过才会写入可用渠道，随后把它设为"已启用"。

## 第 2 步：建知识库（知识库实验台）

创建知识库，向量模型选第 1 步接入并测试通过的那一个。上传企业资料（制度、流程、产品说明、常见问答），等待文档状态变为"完成"。

## 第 3 步：建智能体（智能体工厂）

从模板或空白创建智能体：填写名称、类型、提示词，绑定第 1 步的对话模型和第 2 步的知识库。检索参数保持默认（top_k=3、hybrid）即可起步。

## 第 4 步：验证（调试对话）

进入"调试对话"，选择该智能体，输入真实业务问题。检查三点：回答是否符合业务口径、右侧是否有引用证据（展示来源文档与命中片段）。

验证通过后，即可进入发布中心对外发布（见《发布与密钥管理》）。

## 只做离线演示时

如果暂时没有真实模型 API，可由部署方开启演示模式，界面会标注"演示模型（非真实）"。演示模式仅用于走查流程，不产生真实业务价值。
