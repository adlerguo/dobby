# 术语表

| 术语 | 通俗解释 |
|---|---|
| 智能体（Agent） | 面向某类业务任务的 AI 助手，由提示词、模型、知识库、工具组合而成 |
| 知识库 | 企业专属资料库，让智能体基于内部材料作答 |
| 向量化 / Embedding | 把文字转成可检索的数字表示，是知识库检索的基础 |
| 召回 / 检索 | 根据问题从知识库找出相关片段 |
| top_k | 一次检索期望返回的片段数量 |
| 混合检索（hybrid） | 同时用语义向量和关键词两种方式检索，再融合排序 |
| 引用 | 回答所依据的原文出处，可点击定位 |
| 命中测试 | 上线前用真实问题检验知识库能否召回正确片段 |
| 渠道（Channel） | 一个模型的一路接入（一个 Key/供应商），支持多渠道容错 |
| 已启用模型 | 当前可被直接调用的模型 |
| 发布 / 外部应用 | 把智能体对外开放，供其他系统通过密钥调用 |
| 访问密钥（API Key） | 调用已发布应用的凭证，仅生成时展示一次 |
| 运行轨迹 | 一次对话内各环节（模型/检索/工具）的执行记录 |
| 租户 | 一个隔离的企业空间，租户间数据不互通 |
| 工作空间 | 按项目组织资源、隔离协作的单元 |
