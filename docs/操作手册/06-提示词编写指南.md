# 提示词编写指南

提示词是影响回答质量的最大变量。同一个模型和知识库，提示词写得好坏，回答可用性差距很大。本指南面向业务用户，不需要技术背景。

## 一个可套用的结构

按四段写，照填即可：

1. **身份与任务**：你是谁、为谁服务、解决什么问题。
   > 例："你是公司行政制度助手，面向全体员工，回答报销、考勤、请假等制度问题。"
2. **回答边界**：只答什么、不答什么、依据什么。
   > 例："只依据知识库中的制度文件回答。制度未覆盖的问题，回复'该问题制度未明确，请咨询行政部'，不要猜测。"
3. **输出格式**：结构、长度、语气。
   > 例："先给结论，再列依据条款。回答控制在 200 字内，语气正式简洁。"
4. **不确定时的处理**：找不到依据怎么办。
   > 例："若知识库没有相关内容，明确说明未找到，不要编造。"

## 常见错误

- 只写"你是一个助手"——太空泛，回答会发散。
- 不设边界——模型会自由发挥、编造制度。
- 不要求引用依据——回答无法追溯，业务不敢用。

## 调优方法

写完后到"调试对话"用真实问题测试。回答跑偏就回来收紧边界；回答太啰嗦就在输出格式里限制长度；出现编造就强化"不确定时的处理"那一段。改一处、测一次，逐步逼近可用。
