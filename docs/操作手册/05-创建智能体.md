# 创建智能体

智能体是面向某类业务任务的 AI 助手。

## 两种创建方式

- **从模板创建**：继承场景说明和默认配置，适合快速起步。
- **从空白创建**：自定义名称、类型、提示词、知识库与能力，适合定制场景。

## 配置项逐项说明

1. **基础信息**：名称、类型、说明——写清这个智能体要解决什么任务。
2. **提示词（最关键）**：定义身份、回答边界、输出格式、遇到不确定内容时的处理方式。详见《提示词编写指南》。
3. **模型**：选择已启用的对话模型。
4. **知识库**：绑定一个或多个知识库，作为回答依据。
5. **工具能力**：按需启用（如查询接口、检索等）。
6. **检索参数**：top_k（期望返回片段数，默认 3）、match_type（默认 hybrid 混合检索）。

## 创建后必做验证

进入"调试对话"，输入真实业务问题，重点检查：

- 回答是否符合业务口径（不跑偏、不编造）
- 引用（来源文档与片段）是否来自正确资料
- 多轮追问下是否稳定

通过验证后再进入发布流程。**未验证直接发布是最常见的线上事故来源。**
