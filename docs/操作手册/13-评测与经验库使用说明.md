# 评测与经验库使用说明

> 本模块属于 Cockpit（驾驶舱）子系统，面向持续优化智能体质量的进阶用户。若当前主平台 UI 未完整暴露该模块，可视为二期/进阶能力，以实际交付版本为准。

## 它解决什么

智能体上线后，回答质量需要持续验证和沉淀。这个模块提供两件事：

- **评测（Evals）**：把一批"标准问题 + 期望结果"存成评测用例，批量跑一遍，自动判断通过率，避免每次改动都靠人肉抽查。
- **经验库（Experiences）**：把验证过的好问答、好做法沉淀下来，作为后续优化和复用的参考。

## 评测用例（Eval Cases）

维护一组测试题：每条包含输入问题和期望判断（如是否包含某内容、是否精确匹配、是否要求带引用等）。当你调整了提示词或知识库，用同一批用例回归，看通过率有没有退步。

## 评测运行（Eval Runs）

对某个智能体跑一次全量评测，得到整体通过率和逐条结果。运行支持查看进度。用于：改动前后对比、上线前质量门禁。

## 经验库（Experiences）

把典型问答、有效提示词写法、踩坑与解法记录下来，形成可检索的经验资产，供团队复用，减少重复摸索。

## 建议用法

- 每个上线的智能体，维护一组 10–30 条的核心评测用例作为回归基线。
- 每次调提示词/换模型/更新知识库后，先跑评测再发布。
- 把 POC 和上线中验证过的好做法沉淀进经验库。
