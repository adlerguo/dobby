# 模型接入

模型接入是把外部模型对接进平台，供智能体对话、知识库向量化等能力调用。

## 操作步骤

1. 进入"模型中心 → 模型广场"，查看平台已支持对接的可适配模型。
2. 用供应商、模型类型筛选，找到目标模型，点击"接入使用"。
3. 填写接入信息：
   - 访问密钥（API Key）
   - 服务地址（Base URL）
   - 权重（多渠道时用于分配流量，可留默认）
4. 点击"测试并接入"。平台会做一次真实连通测试，**测试失败不会写入可用渠道**。
5. 测试通过后，模型进入"已接入模型"列表，再将其设为"已启用"。已启用表示当前可被直接调用。

## 多渠道与容错

同一个模型可以接入多个渠道（多个 Key / 多个供应商）。平台会按权重路由，某个渠道失败时自动切换到备用渠道，并对连续失败的渠道做熔断隔离，恢复后自动放回。这一切对使用者透明。

## 关于目录中"即将支持"的模型

部分视觉、语音、图像生成或重排（rerank）模型目前仅在目录中展示，按钮标注"即将支持接入"。这类模型可以浏览，但暂不能接入使用。

## 常见问题

- **测试报 401 / 鉴权失败**：Key 错误、权限不足或账号欠费，请到供应商后台核对。
- **筛选后"可适配模型总数"不变**：该数字是平台支持能力的总量，不随你的筛选或接入状态改变；"已接入 / 已启用"才反映你当前企业的配置。
