# 观测与审计

## 观测中心

用于查看平台运行质量。可按时间段、智能体、状态、运行环节类型筛选，查看：调用趋势、成功率、P95 延迟、Token 用量、按智能体排行。

**运行轨迹**用于定位一次对话里发生了什么：智能体运行、模型调用、知识库检索、工具调用，逐环节可查。排查"某次回答为什么不对"时从这里入手。

数据为空时，先放宽筛选条件，或先完成一次对话再看。

## 审计记录

记录关键操作：模型接入、智能体更新、发布应用、工具绑定、用户管理等。支持按用户、动作、资源类型、时间筛选，并支持通过接口导出（当前以接口数据导出为主；如需现成 Excel/CSV 文件下载，可在交付时按需接入）。适合管理员做合规检查、运维追溯配置变化。

## 谁该看

- 管理员：定期看审计做合规检查。
- 构建者/运维：用运行轨迹排查回答质量问题，用趋势看用量和成本。
- 决策层：看成功率和用量判断哪些智能体在产生价值。
