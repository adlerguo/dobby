# 发布与密钥管理

智能体验证可用后，在"发布中心"创建外部应用，对外提供服务。

## 发布前确认三件事

1. 智能体状态为"已启用"。
2. 绑定的模型和知识库均可正常使用。
3. 调试对话中的回答与引用符合业务要求。

## 发布与密钥

- 在发布中心创建外部应用，发布记录会绑定具体智能体。
- 系统生成访问密钥（API Key）。**密钥完整内容只在生成时展示一次**，请由管理员立即妥善保存。
- 可为密钥设置调用限额：每分钟速率、每日请求数、每日 Token、每日成本。达到上限会拒绝调用，防止超支和滥用。

## 集成方式

外部系统可通过标准接口调用已发布的智能体，支持流式返回。技术对接细节见面向开发者的《OpenAI 兼容 API 接入说明》。

## 密钥的日常管理

- **轮换**：定期更换密钥，旧密钥停用。
- **下线 / 更换**：下线应用或更换密钥时，务必同步通知使用方更新配置，否则会中断调用。
- **版本管理**：记录发布变更，便于回溯不同阶段的上线配置。
