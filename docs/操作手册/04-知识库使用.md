# 知识库使用流程

知识库是企业专属资料库，让智能体基于内部材料作答，并给出可追溯的来源引用（展示来源文档名与命中片段，即片段级引用/摘要；如需页码级原文定位，需结合文档解析能力另行实现）。

## 创建与上传

1. 进入"知识库实验台"，创建知识库，填写名称、类型、说明。
2. 选择用于向量化的模型（须是已接入并测试通过的向量模型）。
3. 上传资料：制度文件、流程说明、产品资料、案例文档、常见问答等。
4. 文档进入解析流程，在文档列表查看状态；状态变为"完成"后才可检索。可打开切片查看原文。

## 命中测试（上线前必做）

正式使用前，用"命中测试"输入真实业务问题，检验知识库能否召回正确片段。命中结果偏少或不准时，按下面调优。

## 让召回更准的实操建议

- **资料要"正式且完整"**：用规范术语的原文，避免口语化摘要。
- **长文档拆分**：把过长的制度拆成小节再上传，命中更精准。
- **用业务正式说法提问**：命中测试时贴近文档里的术语。
- **调参数**：召回偏少可适当降低阈值、增大期望返回数（top_k）。

## 重要限制

**已有文档的知识库不能中途更换向量模型**。这是为避免旧向量被孤立，导致"文档还在但搜不到"。确需换模型时，请新建知识库或执行重建索引流程。
