# 平台介绍

本平台帮助企业在一套工作台里，把"模型接入 → 企业专属知识库 → 智能体配置 → 发布上线 → 运行观测"串成闭环，减少跨系统操作。

## 它能解决什么

面向明确的业务任务构建 AI 助手，典型场景包括制度问答、工单分析、合同审批辅助、内部流程助手等。回答基于企业自己的资料，并可追溯到原文引用。

## 谁来用、各看什么

| 角色 | 主要工作 | 常用入口 |
|---|---|---|
| 平台/租户管理员 | 账号、角色、发布、审计、系统设置 | 平台管理、发布中心、审计记录 |
| 构建者（数智专家） | 配模型、建知识库、调智能体、优化回答 | 模型中心、知识库实验台、智能体工厂 |
| 普通成员（业务） | 使用已发布的智能体问答 | 调试对话 / 已发布应用 |

## 建议的起步方式

从一个明确的业务问题切入（例如"公司报销制度问答"）。先完成模型接入，再准备知识库，随后创建智能体并验证回答质量，最后发布给业务使用。不要一次性铺开多个场景，先跑通一个闭环再复制。

## 左侧菜单速览

工作台（运行概况）、智能体工厂、模型中心、模板广场、知识库实验台、调试对话、发布中心、工具中心、观测中心、审计记录。管理员入口在侧栏底部。
