# 工具中心

工具中心集中管理两类能力：面向智能体的"能力插件"，和面向管理员的"运维工具"。

## 能力插件（给智能体用）

可用于查询数据、调用外部接口、检索知识库或连接 MCP 服务。在智能体配置里启用后，智能体在回答时可按需调用。

## 运维工具（给管理员用）

用于连通性检测、导出、维护类操作。

## 使用方式

- 每个工具有详情页，说明"是什么、给谁用、怎么用"及参数。
- 可用工具支持在线试运行；原始返回数据收纳在"开发者"折叠区，默认不铺开。
- 创建工具可手动新建，也可用对话式构建生成草稿。

## MCP 工具

可按名称、传输方式、服务地址、认证方式配置。当前外部 MCP 执行能力标注"即将支持"，但仍可保存和展示配置，便于提前编排。

## 生产安全默认（重要）

出于安全考虑，平台对高风险工具采取"默认关闭、显式授权"策略：

- **代码类工具默认禁用**（`enable_auto_code_tools=false`）。需管理员显式开启并加入允许清单（`code_tool_allowlist`）后，才能被智能体调用。
- **HTTP 外部调用默认无可访问域名**（`http_tool_allowed_hosts` 为空）。需管理员配置允许访问的主机白名单后才能对外请求。
- **外部 MCP 执行能力**当前标注"即将支持"，可保存配置但暂不执行。

因此"能力插件可由智能体按需调用"的前提是：管理员已完成白名单与权限配置。未配置时，这些高风险能力不会生效。详见《工具安全配置说明》。
