企业智能体中台示例资料

企业智能体中台用于把模型、知识库、工具、发布渠道和审计能力统一管理。平台管理员先在模型中心接入真实大模型 API，并完成连通性测试；业务人员再创建知识库、上传资料、配置智能体并在调试对话中验证回答效果。

知识库问答建议选择真实 embedding 模型。中文资料可以使用 BGE-large-zh、通义 text-embedding-v4 或其他 OpenAI 兼容 embedding 服务。知识库创建后会记录 embedding 维度，已经上传文档的知识库不建议直接切换 embedding 模型，应新建知识库或执行重建索引流程。

智能体发布为 API 后，外部系统需要使用应用 API Key 调用。平台只在生成 API Key 时展示一次明文，后续仅保存哈希和前缀，避免密钥泄漏。调用日志、引用证据和运行轨迹可在观测中心查看。

沙箱执行能力仅面向本地可信环境，用于演示或受控工具调用。多租户 SaaS 场景应替换为 gVisor、nsjail 或独立容器池等强隔离方案。
